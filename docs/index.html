Before you install.

Which platforms are supported?

BusLane targets macOS, Windows, and Linux through one Avalonia codebase.

How are connections protected?

Saved connection strings use local encryption. Optional app lock adds another boundary.

Can I contribute?

Yes. BusLane is MIT licensed, with security guidance in the repository.
